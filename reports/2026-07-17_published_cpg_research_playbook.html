What the published repo promises but does not contain. CLAUDE.md — the first file a reader opens — declares a four-stage pipeline and states that "validation is a hard gate: never select or present a case that has not passed validation." It maps each stage to a file. But only stages 1 and 2's overview are published:
  • agents/01_case_finder.md — published
  • agents/02_validator.md — absent
  • agents/03_selector.md — absent
  • agents/04_slide_builder.md — absent
  • .claude/agents/ax-validator.md — absent, though CLAUDE.md tells the reader to use it by name

Assessment

As a research playbook — which is what the description claims — the published repository delivers: the strategies, the memory systems, the crawl harness, and the harvested corpus are all here, documented, and tested. That half is complete and someone else could genuinely pick it up.

As an implementation of the pipeline CLAUDE.md describes, it is half-published. The discovery stages are in; the validation-and-deck stages are named, required, and missing. A reader following the repo's own front-page instructions hits a wall at stage 2.
