Why those four files matter more than the other 59

CLAUDE.md is the repository's contract, and it opens by mapping every stage to a file:

1. Case Finder — agents/01_case_finder.md → ax_case_db.json
2. Case Integrity Validator — agents/02_validator.md → adds gate_passed
3. AX Case Selector — agents/03_selector.md → main + appendix
4. Executive Slide Builder — agents/04_slide_builder.md → deck_plan.json

Three of those four paths resolve to nothing in the published repository. The same document also instructs the reader to "use the matching subagent in .claude/agents/ (e.g. ax-validator)" — which is likewise absent. The published repo therefore documents a pipeline it cannot run, and names files it does not contain.

The concentration of risk is the finding. The discovery half — 20 days of work, 1,161 entities, 231 cases, 18 tests, a safety harness — is fully committed and pushed. It is safe. The deck half exists as 32 KB across four uncommitted files on one Windows machine, with no backup, no history, and no copy anywhere else. The cheapest work to protect is the least protected.

This is finished design work that simply never got committed.

A second, quieter gap

Stage 2 cannot run today even if its spec were committed, because its declared input is empty. The 231 harvested cases sit in ax_case_harvest_registry.json, while Stage 2 reads ax_case_db.json — which contains {"cases": []}. The harvest path and the pipeline path were built separately and were never joined.

And when the two are joined, a data gap surfaces: transformation_date is unknown for 183 of 231 cases (79%), while Stage 2 validates transformation and publication dates separately and routes out-of-window cases to the appendix. Roughly four in five cases will land in manual review on the date check alone.

What to do about it

  1. Commit the four deck files. agents/02_validator.md, 03_selector.md, 04_slide_builder.md, .claude/agents/ax-validator.md. This removes the single point of failure and makes CLAUDE.md honest. It is a five-minute change against 32 KB of otherwise-unbacked work.
  2. Decide on .claude/settings.json. Commit it or ignore it deliberately — right now it is neither.
  3. Bridge harvest → pipeline. Either feed ax_case_harvest_registry.json into ax_case_db.json, or update CLAUDE.md to name the registry as Stage 2's real input. The current mismatch is silent.
  4. Add state/_* and .scratch_ax/ to .gitignore. 501 scratch files currently show up as untracked noise on every git status, which is exactly how four critical files stayed invisible for a week.
  5. Resolve or delete backup/evidence-url-migration. Its work was superseded by 118fc0c on main; it is now a dangling branch that only exists here.

Items 1–2 and 4–5 are local git hygiene. Item 3 is a design decision worth making explicitly.
